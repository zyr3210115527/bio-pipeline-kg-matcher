# 图谱变更说明：旧版（0723） vs 新版（0811）

> 整理日期：2026-08-11
> 说明对象：旧图谱（基于 0723 标注数据、大写标签）与新图谱（基于 data/0811、小写标签，含新标注数据 + 健康人群 + 新 T2）

---

## 1. 一句话总结

新图谱在**数据、节点/关系命名、属性、空值处理、约束、导入流程**六个方面都发生了变化：数据量整体扩大（新增健康人群 557 人、新 T2 结果、51 个工具）；节点标签和关系类型从大写改为**小写风格**；T1/T2 的语义格式与组学策略做了系统性补全和统一；空值从"空字符串"改为真正的 NULL。

## 4. 关系类型变化

| 关系 | 旧版 | 新版 |
|---|---|---|
| 个体→研究 | `IN_STUDY` | `in_study` |
| 样本→个体 | `IN_INDIVIDUAL` | `in_individual` |
| 研究→项目 | `IN_PROJECT` | `in_project` |
| T1→样本 / 研究 | `IN_SAMPLE` / `IN_STUDY` | `in_sample` / `in_study` |
| T1/T2→格式/级别/模态 | `IN_FORMAT` / `IN_LEVEL` / `IN_MODAL` | `in_format` / `in_level` / `in_modal` |
| T2→T1 溯源 | `GENERATED_FROM` | `generated_from` |
| 工具→功能 | `HAS_FUNCTION` | `has_function` |
| 工具→格式 | `INPUT` / `OUTPUT` | `input` / `output` |
| 工具→工具 | `NEXT_TOOL` | `next_tool` |
| 工具→模态 | `SUITABLE_FOR` | `suitable_for` |

**语义层面的关系变化**：
- `T1_in_modal`（T1→模态）：旧版靠 T1 与 T2 按 run_accession join 取 strategy；新版**直接从 T1.strategy 生成**，不再依赖 T2，并做了策略规范化（WXS→WES、Targeted-Capture→WES、TCR-Seq→bulk_RNA）。
- `T1_in_study`：旧版靠 T1 join individual 反查 study；新版直接读 T1.study_accession。
- T2 关系：旧版 T2 只有健康占位 7 行；新版 T2 为真实分析结果（36759 行），`T2_generated_from_T1` 64545 行。

## 5. 节点属性变化

### 5.1 Project / Study / Tool
- Project：18 列完全一致，仅健康行新增 1 行。
- Study：列名 `tumor_type(以individual里的为准)` → `tumor_type`（对齐导入脚本）。
- Tool：9 列一致；tool_id 由 2 位（T01）改为 3 位（T001）；语义格式拼写归一（`MUTATION_ANNOTATION_FORMA_MAF` → `MUTATION_ANNOTATION_FORMAT_MAF`，与 T2 的 .maf 指向同一 Format 节点）。

### 5.2 Individual（110 列 → 114 列）
- **16 个列名规范化**：括号/特殊字符改为下划线，如
  `who_classification_(2022)` → `who_classification_2022`、`white_blood_cell_counts(×10⁹/l)` → `white_blood_cell_counts_109_l`、`tumor_average_diameter_(cm)` → `tumor_average_diameter_cm` 等。
- **新增 4 列（健康人群独有）**：`population_type`（Natural）、`sample_count`、`file_count`、`organization`。
- 数据内容：新增 557 健康个体 + 1323 个补建个体（仅有样本链路信息，临床/肿瘤字段为空）。

### 5.3 Sample（11 列 → 15 列，结构变化）
- 旧版：样本级（`individual_id`/`biospecimen_anatomic_site`/`tissue_type`/`specimen_type`/`tumor_descriptor`/`experimental_strategy`）。
- 新版：**run 级**（新增 `individual_identifier`/`gender`/`run_title`/`platform`/`strategy`/`sample_description`/`run_accession`/`experiment_accession`），并保留健康人群的 `project_accession`/`tissue_type`/`specimen_type`。

### 5.4 T1（9 列 → 16 列，补全）
- 新数据原始只有 9 列；补全后新增：`T1_id`（文件名::路径）、`semantic_format`、`size`、`platform`、`data_level=1`、`individual_name`、`sample_name`。
- 列名调整：`format` → `file_format`；新增 `study_accession`、`strategy`。

### 5.5 T2（补全 + 策略统一）
- 新 T2 原始 6 列 → 补全为 11 列（`T2_id`、`run_accession`、`sub_file_name`、`format`、`semantic_format`、`data_level=2` 等），新增 `strategy_original`（12 列）。
- **组学策略统一**：以 T1 → sample 的 run 级策略为权威覆盖 T2.strategy（原值存 `strategy_original`）；T2 vs T1 模态冲突从 1892 个 run 降为 0。
- size 科学计数法归一；重复 (文件名,路径) 509 行去重保留 size 大者。

## 6. 空值处理变化

| 项目 | 旧版 | 新版 |
|---|---|---|
| 空值标记 | `Null`/`NOT_FOUND`/`未找到` 等以字符串进图 | 生成阶段统一清洗为空 |
| 导入时空值 | 直接 `row.列` → 空字符串 `''` 存入属性 | `nullIf(row.列, '')` → **真正的 NULL**（181 处） |
| 数值列 | `toInteger('')` → NULL | 不变 |

---

## 7. 约束与索引变化

- **T1/T2 唯一约束修复**：旧版约束建在小写 `t1_id`/`t2_id` 上（与实际属性 `T1_id`/`T2_id` 不符，约束形同虚设）；新版正确绑定 `T1_id`/`T2_id`。
- 标签小写：所有约束/索引的 `FOR (n:Label)` 同步为小写标签。
- 索引清单不变（10 个）；其中 `sample_type_index`（Sample.sample_type）在新 schema 下无对应属性，为无效索引（不影响导入，可后续删除）。
- `00_clear.cypher` 与 schema 名称完全对齐（均带 `IF EXISTS`），可安全清库重导。

## 10. 已知差异 / 需要知晓的点

1. **T1 有 6848 行缺 sample/individual 链接**（新数据源占位值 `未找到` 等被清洗为空）：这些 T1 节点保留，但没有 `in_sample`/`in_individual` 关系（旧版 T1 全部有链接）。
2. **T2 有 3878 行无 run_accession**：不参与 `T2_generated_from_T1` 溯源。
3. **健康 T2 占位 7 行 semantic_format 为空**（自然语言描述未映射）：不建 Format 关系（按你的决定暂缓）。
4. **individual 有 159 个重复 individual_accession**（跨研究重复收录）：按你的决策保留全部行，导入用 MERGE 合并为同一节点。
5. **HRA000122 只有 127 行 T2 结果，没有 individual/sample/T1**（源数据缺口）。
6. **project/study 的计数列与实际行数不一致**（源数据元数据问题，如 HRA000071、HRA000074 等；HRA007167/HRA007169 的 sample_count 疑似写反）。
7. **查询模板（cypher/query_temlpates/）仍是旧模型**（Tool/Data/Cohort + 大写关系），与当前图谱不匹配，需要后续单独重写。
